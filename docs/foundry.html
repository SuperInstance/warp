foundry — the deployment page that compiles plugins

Fill the boxes (human) or set URL params (agent). The page generates a complete quilt-plugin for the warp platform host: module + manifest stub + FAIL-first pin scaffold + README. Deterministic — same params, same bytes, same content hash. Python is read-through, so "compile" is honest: the download is the artifact.

Agent door: curl -s "…/foundry.html?raw=1&name=myvote&caps=vote.ballot,vote.tally&type=ballot" → pipe to platform/plugins/myvote.py. No clicks. The page is the boilerplate.
