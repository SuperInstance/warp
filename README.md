# warp

**Agentic development environment** — an AI-powered code editor and terminal that treats development as an agent coordination problem.

## What This Gives You

- **Agentic coding** — AI agents that can read, write, and execute code
- **Terminal integration** — AI-aware terminal with command suggestion and execution
- **Multi-agent workflows** — coordinate specialized agents for complex tasks
- **Context-aware** — understands your codebase, dependencies, and history

## How It Fits

Development environment for the SuperInstance ecosystem. Uses `a2a-protocol` for agent coordination and `semble` for code search. Part of the agentic development stack.
